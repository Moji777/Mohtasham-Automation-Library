# Integration plan

1. Inventory existing workflows, nodes, dependencies and evidence; read-only first.
2. Map capabilities to the reference projects. Mark each present, missing, partial or unknown.
3. Prioritize CRM, routing, shared knowledge, reliability and content drafts.
4. Reuse n8n and Ollama before adding runtimes. Benchmark CPU/RAM/VRAM; run media workers on demand.
5. Stage changes using synthetic data; test only new or affected functionality. Preserve backups and rollback.
6. Require authorization for real outbound messages, publishing, paid services and irreversible operations. Respect provider eligibility.

No production system has been audited or altered by this library.
